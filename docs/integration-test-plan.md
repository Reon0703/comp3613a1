**Pytest Implementation**  
The scenarios above are implemented in tests/test_integration_workflows.py and run with python -m pytest -q. Tests use a temporary SQLite database, real FastAPI routes and service/repository layers, and temporary upload directories so they do not modify development data or application uploads.  
The complete suite currently reports **79 passed**. Pytest also reports a Starlette deprecation warning about its current httpx test-client integration; it does not affect the test results.
