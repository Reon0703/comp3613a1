# User Acceptance Testing Plan

| Test Case | Pre-conditions | Test Steps | Test Criteria | Success |
|---|---|---|---|---|
| **Test Student Account Creation** | ☐ None | ☐ Open the registration page.<br>☐ Enter a new username, email address, and password.<br>☐ Submit the registration form. | ☐ User receives confirmation that registration succeeded.<br>☐ User is directed to the login page.<br>☐ The new account can be used to sign in as a student. | ☐ Pass ☐ Fail |
| **Test Student Login** | ☐ A student account exists.<br>☐ User is signed out. | ☐ Open the login page.<br>☐ Enter the student username and password.<br>☐ Submit the login form. | ☐ User is signed in and redirected to the application home page.<br>☐ Authenticated navigation and student-specific pages are available. | ☐ Pass ☐ Fail |
| **Test Login Failure** | ☐ User is signed out. | ☐ Open the login page.<br>☐ Enter an incorrect password for an existing account.<br>☐ Submit the login form. | ☐ User remains signed out.<br>☐ An error message is displayed and the login form remains available. | ☐ Pass ☐ Fail |
| **Test Company Creates and Publishes a Vacancy** | ☐ A company account exists and is signed in.<br>☐ A supported field of study is available. | ☐ Open the company vacancies page.<br>☐ Start creating a vacancy.<br>☐ Enter a title, description, location, and field of study.<br>☐ Select `Published` as the status.<br>☐ Submit the vacancy form. | ☐ Success message is displayed.<br>☐ The vacancy appears in the company's vacancy list with `Published` status.<br>☐ A student can find the vacancy in internship browsing. | ☐ Pass ☐ Fail |
| **Test Company Saves a Draft Vacancy** | ☐ A company account exists and is signed in. | ☐ Open the company vacancies page and start creating a vacancy.<br>☐ Enter the required vacancy details.<br>☐ Leave status as `Draft` and submit. | ☐ Vacancy appears in the company's vacancy list as a draft.<br>☐ Vacancy is not visible in student internship browsing. | ☐ Pass ☐ Fail |
| **Test Student Browses Internship Vacancies** | ☐ A student account exists and is signed in.<br>☐ At least one published vacancy and one draft vacancy exist. | ☐ Open the internship browsing page.<br>☐ Browse the available vacancies.<br>☐ Search by a keyword and/or select a field-of-study filter.<br>☐ Move between result pages if pagination is available. | ☐ Published vacancies are displayed; draft vacancies are not shown.<br>☐ Search and filters narrow the displayed results.<br>☐ The selected search/filter state is retained while paging. | ☐ Pass ☐ Fail |
| **Test Student Views Vacancy Details** | ☐ A student account exists and is signed in.<br>☐ At least one published vacancy exists. | ☐ Browse internships.<br>☐ Open a vacancy's details. | ☐ The selected vacancy's description, location, field of study, and company information are shown.<br>☐ The page indicates whether the student has already applied. | ☐ Pass ☐ Fail |
| **Test Student Submits an Application** | ☐ A student account exists and is signed in.<br>☐ A published vacancy is accepting applications.<br>☐ Student has a valid PDF application document no larger than 10 MB.<br>☐ Student has not already applied to this vacancy. | ☐ Open the published vacancy details.<br>☐ Choose the application PDF.<br>☐ Submit the application. | ☐ Confirmation message is displayed.<br>☐ Student is returned to internship browsing.<br>☐ The application appears in the student's application list with `Submitted` status. | ☐ Pass ☐ Fail |
| **Test Student Application Validation** | ☐ A student account exists and is signed in.<br>☐ A published vacancy exists. | ☐ Open the vacancy application form.<br>☐ Attempt to submit without a PDF, with a non-PDF file, or with a PDF larger than 10 MB. | ☐ Submission is rejected with a clear error message.<br>☐ No application is created for the rejected submission. | ☐ Pass ☐ Fail |
| **Test Student Views and Updates Own Application** | ☐ A student account exists and is signed in.<br>☐ Student has an application with `Submitted` status. | ☐ Open the student's application list.<br>☐ Locate the submitted application.<br>☐ Replace its application PDF with a valid PDF. | ☐ Only the signed-in student's applications are listed.<br>☐ The application remains associated with the same vacancy and shows the updated document. | ☐ Pass ☐ Fail |
| **Test Student Withdraws Own Application** | ☐ A student account exists and is signed in.<br>☐ Student has an application that can be deleted. | ☐ Open the student's application list.<br>☐ Choose to delete the application.<br>☐ Confirm or submit the delete action if prompted. | ☐ Confirmation is displayed.<br>☐ The application no longer appears in the student's application list. | ☐ Pass ☐ Fail |
| **Test Company Reviews Applicants** | ☐ A company account exists and is signed in.<br>☐ The company owns a vacancy with one or more student applications. | ☐ Open the company's vacancy list.<br>☐ Open the applicant list for the vacancy.<br>☐ Search or filter applicants, then open an application for review. | ☐ Only applications for the company's vacancy are shown.<br>☐ Applicant details, application status, and submitted document are available for review. | ☐ Pass ☐ Fail |
| **Test Company Shortlists an Applicant** | ☐ A company account is signed in.<br>☐ The company owns a vacancy with an application. | ☐ Open the vacancy's applicant list.<br>☐ Open an application.<br>☐ Choose the shortlist action. | ☐ Confirmation is displayed.<br>☐ Application status changes to `Shortlisted` in the review view and applicant list. | ☐ Pass ☐ Fail |
| **Test Company Rejects an Applicant** | ☐ A company account is signed in.<br>☐ The company owns a vacancy with an application. | ☐ Open the vacancy's applicant list.<br>☐ Open an application.<br>☐ Choose the reject action. | ☐ Confirmation is displayed.<br>☐ Application status changes to `Rejected` in the review view and applicant list. | ☐ Pass ☐ Fail |
| **Test Company Finishes Application Review** | ☐ A company account is signed in.<br>☐ The company owns a vacancy with applications in `Under Review` status. | ☐ Open the vacancy's applicant list.<br>☐ Choose the finish-review action. | ☐ A completion message is displayed.<br>☐ Applications that were `Under Review` change to `Rejected`.<br>☐ Applications already `Shortlisted` or `Rejected` retain their status. | ☐ Pass ☐ Fail |
| **Test Company Updates Vacancy Status** | ☐ A company account is signed in.<br>☐ The company owns a published vacancy with no applications. | ☐ Open the company's vacancy list.<br>☐ Edit the vacancy and change its status to `Closed`.<br>☐ Save the change. | ☐ Updated status is shown in the company's vacancy list.<br>☐ Closed vacancy is no longer available to students for browsing or application. | ☐ Pass ☐ Fail |
| **Test Profile Updates** | ☐ Student and company test accounts exist and are signed in to the appropriate account. | ☐ Open the appropriate profile page.<br>☐ Update the profile fields and save.<br>☐ Reload the profile page. | ☐ A student can view their updated name, email, and education level.<br>☐ A company can view its updated company name, email, phone, and location.<br>☐ Saved changes remain after reloading. | ☐ Pass ☐ Fail |
| **Test Logout** | ☐ User is signed in. | ☐ Choose the logout action.<br>☐ Attempt to open a protected page. | ☐ User is redirected to the login page.<br>☐ Protected pages are no longer available until the user signs in again. | ☐ Pass ☐ Fail |
