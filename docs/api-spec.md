**API Notes**  
- The API base path is /api. JSON request bodies use application/json; file uploads use multipart/form-data.  
- Authenticated requests use the app's signed access_token cookie. The cookie is HttpOnly; production also sets Secure.  
- Responses must not expose password hashes, local file paths, or access tokens. Document metadata may be returned, but file downloads return the file content.  
- Supported vacancy statuses are Draft, Published, and Closed. Only published vacancies are available to student browsing and applications.  
- Application statuses are Submitted, Under Review, Shortlisted, and Rejected. A student may replace an application document only while the application is Submitted; one application per student per vacancy is allowed.  
- The application implements the routes marked [Implemented] in this specification as JSON APIs while preserving the existing HTML page and form routes.
